# Объектно-ориентированное программирование

Лабораторные работы по курсу ООП, НИЯУ МИФИ, 1 курс.

## Содержание

| Лабораторная | Тема |
|---|---|
| 1 | Перегрузка функций. Слогоделение русских слов (работа с `const wchar_t*` и `wstring`) |
| 2 | Классы и наследование. Простое и сложное домино — проект с меню и тестами |
| 3 | Многопоточность и паттерны. Симуляция охранной системы: Платформа, Сенсоры, AI-анализатор, Злоумышленник |

## Ключевые темы курса

- Перегрузка функций и операторов
- Классы, наследование, виртуальные методы
- Умные указатели, управление памятью
- Многопоточность (`std::thread`, `std::future`, `std::mutex`)
- Паттерны проектирования (в рамках ЛР 3 — MVC-подобная архитектура: Model/View/Controller)

## Стек

- **C++** (C++17)
- **CMake** — сборка

## Сборка

Каждая лабораторная собирается отдельно:

```bash
cd 2 && mkdir build && cd build && cmake .. && make
```
